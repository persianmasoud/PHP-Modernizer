# Decision 001

Date:
2026-08-04

Title:
PHP Modernizer is a Migration Platform

Decision:

PHP Modernizer will not be limited to PHP compatibility checking.

It will become a complete legacy application modernization platform.

Scope includes:

- PHP version migration
- Server compatibility analysis
- Database migration
- Charset repair
- Backup and rollback
- Interactive migration wizard
- Automated fixes
- Migration reports

Reason:

Real-world legacy projects require more than code analysis.
They need a safe and guided migration process.
