# Decision 006

Date:
2026-08-05

Title:
Rule Engine Knowledge Model Standard


## Decision

PHP Modernizer will implement a modular Rule Engine architecture.

The Rule Engine will be considered the knowledge layer of the modernization platform.

It will not be limited to PHP compatibility checks.

Rules will represent migration knowledge and modernization decisions.


## Analyzer and Rule Engine Separation

The Analyzer and Rule Engine will have separate responsibilities.

Analyzer responsibility:

- Detect technical patterns
- Collect evidence
- Extract project information


Rule Engine responsibility:

- Apply modernization knowledge
- Evaluate detected issues
- Generate recommendations
- Define migration strategies


## Rule Design Principles

Rules must be:

- Modular
- Extensible
- Version-aware
- Independent from the Core Engine


## Rule Metadata

Each Rule may contain:

- ID
- Name
- Category
- Type
- Severity
- Priority
- Confidence
- Source Version
- Target Version
- Dependencies
- Conflicts
- Execution Order
- Evidence
- Recommendation
- Fix Strategy
- Validation Method


## Rule Categories

Initial categories:

- PHP Compatibility
- Security
- Database
- Charset
- Configuration
- Architecture Modernization
- Quality Improvement


## Rule Execution Model

Rules may support different execution modes:

- Detection Only
- Suggestion
- Require Confirmation
- Automatic Apply


## Rule Dependency Model

Rules may depend on other rules.

The engine must support dependency resolution and execution ordering.


## Rule Conflict Management

The architecture should support identifying conflicting rules and recommendations.


## External Rule Support

The Rule Engine should be designed to support:

- Core Rule Packs
- Community Rule Packs
- Custom Rules


## Architecture Modernization Support

PHP Modernizer will support future analysis of legacy architecture.

Examples:

- Mixed responsibilities
- Lack of separation
- Module candidates
- Refactoring opportunities


## Reason

Legacy modernization requires more than syntax compatibility.

A successful migration needs knowledge about:

- Technology versions
- Architecture evolution
- Safe transformation
- Human decision points


## Final Statement

PHP Modernizer is designed as a modernization platform, where the Rule Engine acts as the bridge between analysis and migration.
