# PHP Modernizer Documentation

## Purpose

This directory contains all technical and project documentation for PHP Modernizer.

The documentation is organized into small, focused documents. Each document covers a single topic and is designed to be easy to read, maintain, and update.

---

## Documentation Structure

| Directory | Purpose |
|-----------|---------|
| architecture/ | System architecture and technical design |
| decisions/ | Architecture Decision Records (ADRs) |
| guides/ | Development and documentation standards |
| ideas/ | Future ideas and research notes |
| project/ | Current project status and overall progress |
| roadmap/ | Planned milestones and future releases |
| sessions/ | Development session history |

---

## Documentation Principles

- One topic per document
- Maximum two pages per document
- Avoid duplicated information
- Link related documents instead of repeating content
- Keep documentation up to date with the project

---

## How to Navigate

If you are new to the project, read the documents in this order:

1. Project
2. Roadmap
3. Architecture
4. Decisions
5. Guides

Session notes and Ideas are optional references.

---

## Contributing

When adding new documentation:

- Choose the correct directory.
- Keep documents focused.
- Follow the documentation standards.
- Update related documents when necessary.
