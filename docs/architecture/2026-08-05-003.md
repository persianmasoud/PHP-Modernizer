# Architecture: Analyzer and Rule Engine

Date:
2026-08-05

Title:
Analyzer and Rule Engine Architecture


## Overview

PHP Modernizer uses a modular architecture where analysis logic and migration knowledge are separated.

The Analyzer system is responsible for detecting application elements and collecting technical information.

The Rule Engine is responsible for applying modernization knowledge based on migration requirements.


## Architecture Flow

The modernization analysis flow:

Source Application

↓

Scanner

↓

Analyzer

↓

Rule Engine

↓

Issue Generation

↓

Report Generation

↓

Migration Workflow


## Analyzer Layer

The Analyzer layer is responsible for:

- Reading application structures
- Detecting code patterns
- Finding compatibility problems
- Collecting technical information
- Creating analysis results


Analyzer components should not contain migration rules directly.

The Analyzer identifies facts.

Example:

Analyzer detects:
mysql_connect()

The Analyzer does not decide whether it is valid or invalid for a target version.


## Rule Engine Layer

The Rule Engine represents migration knowledge.

Rules define:

- Source version
- Target version
- Affected feature
- Compatibility status
- Severity
- Migration recommendation
- Validation requirements


Example:

A Rule can define:
PHP 5.6 → PHP 8.2

Feature:
mysql_connect()

Status:
Removed

Severity:
High

Recommendation:
Use PDO or mysqli


## Version Migration Model

PHP Modernizer should understand version migration paths.

Examples:
PHP 5.6 → PHP 8.2

PHP 7.4 → PHP 8.4

PHP 8.1 → PHP 8.3

Rules should be evaluated according to:

- Source PHP version
- Target PHP version
- Migration path


## Rule Categories

Future rule categories include:

- PHP compatibility rules
- Removed functions
- Syntax changes
- Extension changes
- Configuration changes
- Security rules
- Database compatibility rules
- Charset rules


## Extensibility

The architecture allows adding new analyzers and rules without changing the core engine.

Future analyzers may include:

- PHP Compatibility Analyzer
- Security Analyzer
- Database Analyzer
- Charset Analyzer
- Code Quality Analyzer


## Design Principle

The core principle:

> Analyzer detects. Rule Engine understands. Migration Workflow executes.


## Future Expansion

PHP Modernizer focuses on PHP modernization.

However, reusable architecture concepts may support other modernization domains in the future:

- Analyzer framework
- Rule system
- Migration workflow
- Validation engine


## Reason

Separating analysis from migration knowledge provides:

- Easier maintenance
- Support for new PHP versions
- Custom migration rules
- Safer automated fixes
- Better project scalability
