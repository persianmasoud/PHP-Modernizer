# Database

## Purpose

This directory contains database-related resources for PHP Modernizer.

## Planned Features

- Database engine detection
- Connection configuration analysis
- Legacy database compatibility checks
- Migration support
- Backup and restore planning

## Supported Databases (Future)

- MySQL / MariaDB
- PostgreSQL
- SQL Server
- SQLite

## Notes

Database operations must follow these principles:

- Backup before any change
- User confirmation before migration
- Detailed error reporting
- Rollback support when possible
