# PHP Modernizer

## About

PHP Modernizer is an open-source project focused on helping developers migrate legacy PHP applications to modern PHP versions such as PHP 8.2+.

## Project Vision

Many business applications were written years ago using older PHP versions.
This project aims to provide tools and guidance for:

- Detecting deprecated PHP functions
- Identifying PHP 8.x compatibility issues
- Database charset and UTF-8 repair assistance
- Migration documentation and automation tools
